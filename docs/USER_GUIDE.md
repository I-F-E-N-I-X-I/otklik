# Руководство пользователя

На первом запуске выбран демопроект. «Запустить» включает сервер; «Остановить» освобождает порт. Адрес можно скопировать. Порт — 1024–65535, по умолчанию 3001.

## Редактор
Добавьте маршрут кнопкой + слева. Задайте метод и путь, например GET /api/products. В «Ответах» задайте имя, статус 200–599, Content-Type, задержку 0–60000 мс, заголовки JSON-объектом и тело (до 1 МиБ). «Применить маршрут» проверяет конфигурацию. JSON можно форматировать. При переходе между ответами/маршрутами редактор сохраняет введённые поля; исправьте некорректный ввод перед переходом.

Для каждого маршрута нужен включённый fallback. Во вкладке «Правила» добавляйте строки условий: source query/header/body/path, key, operator equals/contains/exists, value. Все условия AND. Ответы проверяются сверху вниз, кнопки ↑/↓ меняют приоритет. Пустой набор условий сам по себе не выбирает ответ: используется явный fallback.

Во вкладке «Сценарий» выберите sequence, перечислите номера ответов через запятую (1,2,3), окончание holdLast или loop. Шаг расходуется при принятии запроса, до задержки. «Сброс сценария» сбрасывает все счётчики; stop/start также сбрасывает. Редактирование не влияет на работающий снимок: перезапустите сервер.

## Файлы
«Сохранить» записывает JSON атомарно; «Экспорт» создаёт копию. «Открыть» проверяет файл до замены проекта. Перед заменой/закрытием есть Save/Discard/Cancel. «Импорт OpenAPI» создаёт новый проект с предупреждениями; поддерживается 3.0.x JSON, paths/operations, application/json и text/plain, example/examples.value. $ref не разрешаются; без примера создаётся placeholder.

## Проверка
Кнопка «Тест GET» отправляет GET текущего пути. Для POST используйте клиент:
```
curl.exe http://127.0.0.1:3001/api/products?category=books
curl.exe -i http://127.0.0.1:3001/api/retry
Invoke-RestMethod http://127.0.0.1:3001/api/products
```
Для POST /api/login создайте ответ с условием body / role / equals / admin, затем отправьте `curl.exe -X POST -H "Content-Type: application/json" -d '{"role":"admin"}' http://127.0.0.1:3001/api/login` (экранирование зависит от оболочки).

## Журнал
Последние 500 запросов; выберите строку для деталей, очистите или экспортируйте JSON. Authorization/Cookie/Set-Cookie/X-Api-Key скрыты. Тела могут содержать ваши данные, журнал хранится только локально. Превью ограничено 32768 символами. Тело запроса ограничено 1 МиБ (413).

Portable запускается из папки. install.ps1 копирует приложение в LocalAppData/Отклик и создаёт ярлык; uninstall.ps1 удаляет только неизменённые файлы из списка установки и ярлык. Пользовательские и изменённые файлы сохраняются. Рекомендуется хранить проекты в отдельной папке. Автономный пакет self-contained уже содержит .NET; framework-dependent требует Desktop Runtime и ASP.NET Core Runtime .NET 10 x64.
