# Поставка

Публичный проект: https://github.com/I-F-E-N-I-X-I/otklik

Готовая программа распространяется как portable ZIP в GitHub Releases. Автономный пакет включает среду .NET; установка через setup.exe не требуется. Для запуска нужно распаковать весь архив.

В репозитории находятся исходники, примеры, демонстрационный магазин и документация. Исторический внутренний план, материалы колледжа и локальные резервные копии не входят в публичную поставку.

Самостоятельный сайт распространения не является частью этой публикации. Актуальный способ загрузки — раздел Releases.

Результаты выполненных проверок и ограничения описаны в VERIFICATION.md. Полная ручная проверка на чистой Windows и разных DPI остаётся отдельным этапом.
